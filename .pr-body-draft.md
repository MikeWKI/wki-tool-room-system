### After the API deploy

`backend/data/enrichment-from-jb.json` sets `engineFamily` from the 2026-02-04 JB category label: 24 MX, 73 Cummins, 12 Detroit (109 part numbers). CAT Tools and General Tools in that file are NOPN-only, so they are not included. Manufacturer, specs, and source URLs stay null. The POST does not create or delete parts.

```bash
API=https://wki-tool-room-system-1.onrender.com

# 1) Preview ~95 days of roster history. Does not write.
curl -sS -X POST "$API/api/audit/load-activity" \
  -H 'Content-Type: application/json' \
  -d '{"pin":"'"$MANAGE_PIN"'","confirm":false}'

# 2) Write that history. Replaces only the previous activity batch.
curl -sS -X POST "$API/api/audit/load-activity" \
  -H 'Content-Type: application/json' \
  -d '{"pin":"'"$MANAGE_PIN"'","confirm":true}'

# 3) Apply the JB category engine-family file. Run from a clone of this branch.
curl -sS -X POST "$API/api/parts/enrich-batch" \
  -H 'Content-Type: application/json' \
  --data-binary @backend/data/enrichment-from-jb.json

curl -sS "$API/api/parts/enrichment-coverage"
```
