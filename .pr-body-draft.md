## Deploy notes

- Frontend: `https://wki-tool-room-system.onrender.com`
- API: `https://wki-tool-room-system-1.onrender.com`
- Keep `MANAGE_PIN` and `CAMERA_ACCESS_PASSWORD` on the API only.
- Do not set `RECONCILE_APPLY_TO_LIVE=true` in this deploy unless someone explicitly wants the gated fill-gaps write.

### Enrichment

```bash
cd backend
node scripts/load-enrichment.js ./data/enrichment.json --apply
```

Or `POST /api/parts/enrich-batch` with `{ "items": [ ... ] }`.

### Shop activity (after the API deploy)

```bash
API=https://wki-tool-room-system-1.onrender.com
curl -s -X POST "$API/api/audit/load-activity" \
  -H 'Content-Type: application/json' \
  -d '{"pin":"'"$MANAGE_PIN"'","confirm":false}'
curl -s -X POST "$API/api/audit/load-activity" \
  -H 'Content-Type: application/json' \
  -d '{"pin":"'"$MANAGE_PIN"'","confirm":true}'
```

Preview first (`confirm: false`). `confirm: true` writes history and replaces only the previous activity batch.
